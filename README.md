# 🌍 World Travel

## Sobre o projeto

O World Travel é uma aplicação web que permite aos utilizadores organizar os seus destinos de viagem e planear experiências que gostariam de realizar em diferentes países.

O objetivo é criar uma plataforma onde cada utilizador possa construir a sua própria lista de destinos, adicionar atividades e acompanhar os seus planos de viagem.

## Funcionalidades previstas

- [ ] Consultar uma lista de países.
- [ ] Adicionar países à lista pessoal.
- [ ] Registar atividades e experiências por país.
- [ ] Editar e eliminar atividades.
- [ ] Criar conta e iniciar sessão.
- [ ] Gerir destinos e atividades individualmente.
- [ ] Guardar informação numa base de dados.
- [ ] Consultar o estado das viagens e atividades.

## Arquitetura

A aplicação será desenvolvida com uma arquitetura separada entre frontend e backend.

O frontend será responsável pela interface e interação com os utilizadores. O backend disponibilizará uma API REST responsável pela lógica de negócio e comunicação com a base de dados PostgreSQL.
